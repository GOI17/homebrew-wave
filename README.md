# Homebrew Tap For Wave

Install [Wave](https://github.com/GOI17/wave):

```bash
brew tap GOI17/wave
brew install wave
```

Upgrade or uninstall with standard Homebrew commands:

```bash
brew upgrade wave
brew uninstall wave
```

Wave currently supports capture and migration preview workflows. Read the
[Wave safety limits](https://github.com/GOI17/wave#safety-limits) before use.
